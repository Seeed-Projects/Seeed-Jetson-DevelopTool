# Seeed Jetson Develop Tool — UI 设计优化规划

## 一、当前核心问题诊断

### 1. 动态反馈缺失（最影响"生动感"）
| 场景 | 现状 | 问题 |
|------|------|------|
| 页面切换 | `QStackedWidget.setCurrentIndex()` 瞬间切换 | 生硬，无过渡 |
| 卡片 Hover | 部分有背景色变化，但无位移/阴影变化 | 平淡，缺乏触感 |
| 按钮点击 | 仅有 `:pressed` 样式变化 | 无缩放/波纹反馈 |
| 加载状态 | 静态文字 "Checking..." 或空白 | 无骨架屏/旋转动画 |
| 操作完成 | 日志追加一行文字 | 无 Toast 通知/成功动画 |
| 列表渲染 | `QTimer` 分批挂载 | 有渐进效果但无入场动画 |

### 2. 视觉层次单调
- 所有卡片使用相同的 `make_card()` 样式，缺乏**尺寸层次**（大卡片 vs 小卡片）
- 阴影是静态的，没有随 Hover 动态加深
- 信息密度高但缺乏**呼吸空间**（留白不足）
- 状态变化仅靠颜色切换（绿→橙→红），无过渡动画

### 3. 色彩运用保守
- 品牌绿 `C_GREEN` 仅用于按钮和选中态
- 无渐变流动、脉冲、发光等动态色彩效果
- 错误/警告状态颜色突兀（突然变红），无过渡

### 4. Flash 页面技术债务
- 1832 行 God Function，完全脱离 `PageBase` 设计系统
- 80+ 处硬编码内联样式
- 自定义按钮与 `theme.py` 工厂函数不一致

### 5. 主题一致性破坏
- Apps 安装对话框使用**浅灰标题栏**（`#f0f0f0`），与全局深色主题冲突

---

## 二、分层优化方案

### 🔴 立即见效（今天可完成）

#### 1. 页面切换动画
**方案**：用 `AnimatedStackedWidget` 替代 `QStackedWidget`
- 侧边栏点击 → 内容区**淡入淡出**（200ms）或**水平滑动**（300ms）
- 参考 Onboarding 引导的淡入淡出效果

#### 2. 卡片 Hover 抬升效果
**方案**：增强 `make_card()`，添加鼠标进入/离开时的动态阴影
- Hover 时：卡片**上移 2px** + 阴影扩散 + 顶部高光边亮度提升
- 使用 `QPropertyAnimation` 实现平滑过渡（200ms）

#### 3. 全局 Toast 通知系统
**方案**：新建 `ToastNotification` 浮动组件
- 操作成功/失败/警告时，从右上角滑入通知
- 支持 4 种类型：success（绿）/ error（红）/ warning（橙）/ info（蓝）
- 自动 3 秒后淡出消失，支持手动关闭
- 替代当前"日志追加一行"的简陋反馈

#### 4. 按钮点击微交互
**方案**：给主按钮添加点击时的**缩放反馈**
- 点击瞬间 `scale(1.0 → 0.96 → 1.0)`，duration 150ms
- 给 `make_button(primary=True)` 统一添加

#### 5. 修复 Apps 对话框亮色标题栏
**方案**：将 `_InstallDialog` 标题栏改为深色主题

---

### 🟡 短期优化（1-2 天）

#### 6. 列表项入场动画
**方案**：Apps/Skills/Devices 的列表项添加**交错淡入上浮**动画
- 每项 `opacity(0→1)` + `translateY(15px→0)`
- Stagger 间隔 40ms，营造"瀑布流"感

#### 7. 骨架屏（Skeleton Screen）
**方案**：数据加载时显示骨架占位，而非空白或 "Loading..."
- 灰色脉冲动画条模拟文字和按钮位置
- 加载完成后骨架淡出，真实内容淡入

#### 8. 状态标签过渡动画
**方案**：Devices 诊断状态变化时，颜色过渡 + 对勾/感叹号缩放弹出
- `checking` → `ok`：灰→绿，对勾图标 `scale(0→1)`
- 使用 `QPropertyAnimation` 颜色插值

#### 9. 空状态插图
**方案**：无数据时显示精美插图 + 引导文案，而非简单 "No data"
- 使用 QPainter 绘制简笔画风格插图（类似 Onboarding）

---

### 🟢 中期重构（1 周）

#### 10. Flash 页面组件化拆分
**方案**：将 1832 行的 `build_page()` 拆分为独立 Widget 组件
- 提取 WizardStepBar、DeviceSelector、RecoveryGuidePanel、FlashProgressPanel
- 统一使用 `theme.py` 工厂函数替换内联样式

#### 11. 统一对话框基类
**方案**：提取 `BaseLogDialog` 基类
- 复用标题栏、底部按钮栏、日志区域、居中逻辑
- 统一深色主题

#### 12. 数据可视化图表
**方案**：Devices 页面添加温度/存储趋势微图表
- 使用 QPainter 绘制迷你折线图

## 三、设计原则

1. **渐进增强**：不破坏现有功能，只在原有基础上叠加动画和视觉效果
2. **性能优先**：动画使用 `QPropertyAnimation` 或 `QTimer` + `update()`，避免阻塞主线程
3. **一致性**：所有动画遵循统一的时长规范（微交互 150ms，过渡 200-300ms，通知 300ms）
4. **可关闭**：所有动画效果可通过配置禁用（考虑低性能设备）
5. **不要过度**：动画是调味剂不是主菜，保持克制（参考 Apple / Linear 的设计哲学）
